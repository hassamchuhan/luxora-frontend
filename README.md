# LUXORA — Modern Lifestyle & E-Commerce Frontend Concept

A sleek, minimalist, and fully responsive e-commerce homepage concept designed and built from scratch. This project focuses entirely on clean visual aesthetics, advanced layout structures, and native CSS capabilities without relying on JavaScript libraries or frameworks.

---

## ✨ Project Overview

**LUXORA** is conceptualized as a high-end lifestyle brand offering curated everyday essentials, technology, and lifestyle products. The primary goal of this project was to master advanced layouts, dark-mode design systems, and responsive user interfaces using pure frontend fundamentals.

> **Note on Functionality:** This project is intentionally built **exclusively with HTML5 and CSS3**. The links and buttons are non-functional placeholders (`href="#"`), as the core focus of this build is to showcase precision frontend design, layout architecture, and a strong grip on styling fundamentals.

---

## 🚀 Key Features

*   **Responsive Navigation & Mobile Menu:** Features a custom pure CSS interactive hamburger menu toggle using sibling selectors (`:checked`), completely avoiding JavaScript.
*   **Modern CSS Architecture:** Built using CSS Grid and Flexbox for fluid, scalable alignments across varying screen sizes.
*   **Unique Geometric Product Art:** Features custom-styled CSS product shapes (bottles, speakers, lamps, and watches) built with absolute positioning and borders.
*   **Cohesive Dark-Mode Theme:** Designed with a sophisticated dark palette (`#0B1220`) accented by electric blue and cyan gradients (`#4DA3FF` to `#67E8F9`).
*   **Fully Responsive Layout:** Optimized smoothly for mobile devices, tablets, and desktop screens using targeted media queries (`max-width: 768px`).

---

## 🛠️ Built With

*   **HTML5:** Semantic markup (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`) ensuring proper document flow and accessibility structure.
*   **CSS3:** Custom properties, CSS Grid, Flexbox, animations, keyframes, transitions, and relative clamp typography.

## 💡 What I Learned

Building Luxora helped solidify key core concepts in frontend development:
*   Mastering complex layout alignment using **CSS Grid** and **Flexbox**.
*   Implementing fully functional UI components (like mobile navigation and dropdowns) using **pure CSS states** instead of scripting.
*   Designing with a strict **design system** (consistent spacing scales, color variables, and reusable modifier classes).
*   Writing clean, organized, and thoroughly commented codebases for better maintainability.
